# Hinweis für Agenten

**Wie du schreibst.** Jeder Text, den du erzeugst — Plan, Baubericht, Manifesttext, Vorlage,
Übergabemeldung, Commit-Nachricht, Issue, Pull-Request-Beschreibung, Kartentitel auf einer
Projekttafel, Fehlermeldung — folgt `CONTRIBUTING.md` (Regeln `SPR-1` bis `SPR-9`). **Lies
diese Datei, bevor du den ersten Text schreibst.**

In einem Satz: Der Coding-Harness muss für eine Person **ohne IT-Hintergrund steuerbar und
verständlich** sein. Wer freigibt, trägt das Risiko; wer das Risiko trägt, muss vorher
verstanden haben, wofür.

**Was für dich sonst gilt, steht in `CLAUDE.md`.** Diese Datei hier ersetzt sie nicht — sie
ergänzt nur den einen Punkt, den ein Agent sonst nirgends findet.
